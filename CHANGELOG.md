## [Unreleased]

### Додано
- **Багаторівнева вкладеність цитат.** Вкладені `<blockquote>` більше не
  схлопуються в один рівень — кожен рівень додає префікс `> ` (CommonMark
  `> > text`). `<blockquote>a<blockquote>b</blockquote></blockquote>` →
  `> a\n>\n> > b`.

### Виправлено (розвідка №2/№3 — «важкі» HTML-кейси)
- **Code-fence конфліктував із вмістом.** `<pre><code>```</code></pre>` давав
  fence із 3 бектиків усередині 3-бектикового коду → зламаний блок. Тепер
  довжина fence динамічна: на 1 більша за найдовший backtick-run (`_fence_for`).
- **Inline-код із бектиком ламався.** `<code>a`b</code>` → `` `a`b` `` (розрив).
  Реалізовано CommonMark-правило: делімітер `` `` ``…`` `` довший за внутрішні
  runs + паддінг-пробіл, якщо контент межує з бектиком (`_inline_code`).
- **`<pre>` у `<blockquote>` рендерився як однорядковий inline-код.** Тепер це
  повноцінний fenced-блок з префіксом `> ` на кожному рядку. `_process_blockquote`
  переписано на блок-свідомий `_blockquote_inner` (зберігає `<pre>`, заголовки,
  `<hr>`, списки, вкладені цитати як окремі сегменти).
- **Заголовки/hr у `<blockquote>` втрачали розмітку** (`> Title` замість
  `> ## Title`). Виправлено.
- **Пробіли в URL ламали посилання/зображення.** `href="/a b c"` тепер
  percent-кодується у `/a%20b%20c` (`_encode_url`) для inline/блок-лінків і картинок.
- **Крайові пробіли в `<strong>`/`<em>`/`<del>` давали невалідні маркери.**
  `<strong> bold </strong>` → `** bold **` (не курсивилось). Тепер пробіли
  виносяться назовні (`a **bold** b`), а порожній/whitespace-only вміст не лишає
  зіпсованих `**`/`*` (`_emphasis`).
- **Сусідні посилання злипались.** Некоректно вкладені `<a>…<a>…</a></a>`
  (BS4 → сусідні) давали `[out](/o)[in](/i)`; крайові пробіли тепер зберігаються
  → `[out](/o) [in](/i)`.
- **Image-link на блок/root рівні губив `href`.** `<a href="/l"><img></a>` поза
  `<p>` рендерився як `![alt](src)` (лінк втрачено). Тепер `[![alt](src)](/l)`.
- **Кілька `<p>` у `<li>` склеювались в один рядок.** Тепер зберігаються як
  окремі параграфи (loose list): `<li><p>a</p><p>b</p></li>` → `- a\n\nb`.
- **Тести:** додано `test/test_hard_cases.py` (30 «важких» + 25 edge) та
  `test/test_edge_cases_advanced.py` (30 складних комбінацій + property-checks);
  дослідницький скрипт `probe2.py`.


### Виправлено (не-табличні конструкції)
- **Заголовки склеювали слова.** `<h*>` рендерився через `get_text()`, а
  selectolax не вставляє роздільник між дочірніми вузлами — `<h2><span>Hello
  </span> <span>World</span></h2>` давав `## HelloWorld`. Тепер заголовок
  рендериться inline-обходом (зберігає посилання/код) і схлопується в один рядок.
- **Block-діти злипались в inline-обході.**
  `<blockquote><p>P1</p><p>P2</p></blockquote>` → `> P1P2`,
  `<li><p>a</p><p>b</p></li>` → `- ab`, вкладений `<blockquote>` → `outerinner`.
  Додано явні межі блоків (`_INLINE_BLOCK_BOUNDARY`) + маркер для `<li>`.
- **Зображення в параграфі губились.** `<p><a href="/l"><img …></a></p>`
  відкидався цілком, бо параграф не мав тексту. `<img>` тепер має inline-рендер
  (`![alt](src)`, з повагою до `include_images`/`normalize_urls`), а параграф із
  самим лише медіа не відкидається.
- **`<ol start="N">` ігнорувався** — нумерація завжди починалася з 1.
- **Legacy-обгортки та голий текст губились**: `<center>`, `<u>`, `<font>`,
  `<details>`, `<summary>` тепер обробляються як контейнери, а текстові вузли
  прямо в корені (`<body>текст</body>`) більше не зникають.

### Додано
- `test/test_non_table_constructs.py` — 42 регресійні тести (21 кейс × обидва
  парсери: selectolax і BeautifulSoup) на списки, заголовки, blockquote,
  зображення, definition list, code-блоки та legacy-розмітку.

## [0.1.0] - 2026-06

### Додано
- Пакування для PyPI (`pyproject.toml`, `MANIFEST.in`, ліцензія MIT).
- Консольна команда `html2md` (точка входу `main_service:main`).
- Документація на MkDocs Material (`mkdocs.yml`, тека `docs/`).
- Повний README українською: встановлення, приклади, API, опції.

### Наявне (успадковано з поточного коду)
- Конвертація HTML → Markdown через Selectolax або BeautifulSoup (Adapter Pattern).
- Видалення шуму за тегами/класами/`id`/`aria-hidden`/`display:none`.
- Виділення основного контенту (link-density / content-density).
- Inline та reference-style посилання, очищення UTM/tracker-хвостів (courlan).
- Цитати `[1]`, `[2]` та список джерел.
- Опційні: витяг дат (htmldate), санітизація (nh3), encoding-fix (ftfy),
  boilerplate-екстракція (trafilatura).
- Синхронний та асинхронний API, ленивий `raw_markdown`.
